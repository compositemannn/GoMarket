# GoMarket

Backend для небольшого маркетплейса, разработанный на Go.

## О проекте

GoMarketplace — учебный backend-проект, который имитирует
основные процессы маркетплейса: продавцы размещают товары,
а покупатели могут находить товары, добавлять их в корзину
и оформлять заказы.

Проект создаётся с целью изучения разработки backend-сервисов
на Go и подготовки к стажировке на позицию Go Backend Developer.

## Основные возможности

### Покупатель

- регистрация и авторизация
- просмотр каталога товаров
- поиск и фильтрация товаров
- просмотр информации о товаре
- добавление товаров в корзину
- изменение количества товаров в корзине
- оформление заказа
- просмотр истории заказов
- отмена заказа

### Продавец

- регистрация и авторизация
- создание товара
- редактирование товара
- удаление товара
- изменение цены
- управление остатками
- просмотр заказов, содержащих его товары
