# GoMarket

Backend для небольшого маркетплейса, разработанный на Go.

## О проекте

GoMarketplace — учебный backend-проект, который имитирует
основные процессы маркетплейса: продавцы размещают товары,
а покупатели могут находить товары, добавлять их в корзину
и оформлять заказы.

Проект создаётся с целью изучения разработки backend-сервисов
на Go и подготовки к стажировке на позицию Go Backend Developer.

## Основные возможности

### Покупатель

- регистрация и авторизация
- просмотр каталога товаров
- поиск и фильтрация товаров
- просмотр информации о товаре
- добавление товаров в корзину
- изменение количества товаров в корзине
- оформление заказа
- просмотр истории заказов
- отмена заказа

### Продавец

- регистрация и авторизация
- создание товара
- редактирование товара
- удаление товара
- изменение цены
- управление остатками
- просмотр заказов, содержащих его товары

## Functional Requirements

### Authentication

- Пользователь может зарегистрироваться.
- Пользователь может авторизоваться.
- Пользователь имеет одну из ролей: buyer или seller.
- Защищённые endpoints требуют авторизации.

### Products

- Продавец может создать товар.
- Продавец может изменить свой товар.
- Продавец может удалить свой товар.
- Покупатель может просматривать товары.
- Покупатель может искать товары.
- Покупатель может фильтровать товары по категории.
- Покупатель может сортировать товары.
- Каталог поддерживает pagination.

### Cart

- Покупатель может добавить товар в корзину.
- Покупатель может изменить количество товара.
- Покупатель может удалить товар из корзины.
- Покупатель может получить содержимое корзины.

### Orders

- Покупатель может создать заказ из корзины.
- При создании заказа проверяется наличие товара.
- После успешного создания заказа остаток товара уменьшается.
- Покупатель может просматривать свои заказы.
- Покупатель может отменить заказ в допустимом статусе.
- Продавец может просматривать заказы со своими товарами.


## Цели проекта

Проект создаётся для практического изучения:

- разработки REST API на Go;
- работы с PostgreSQL и SQL;
- проектирования backend-архитектуры;
- конкурентного программирования в Go;
- работы с context и graceful shutdown;
- тестирования backend-приложений;
- Docker и CI/CD;
- кэширования с Redis;
- аутентификации и middleware.
